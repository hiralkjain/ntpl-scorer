NTPL BLR CRICKET TOURNAMENT — CHAT HANDOFF / PROJECT CONTEXT
==============================================================

We are building a deployable cricket tournament website using React + TypeScript + Vite + Tailwind + Supabase PostgreSQL + Supabase Realtime. No separate custom backend is planned.

TOURNAMENT
- 5 teams.
- 13 registered players per team.
- Exactly 9 players play each match.
- Each team plays 4 league matches.
- Top 2 teams go to the final.
- 10 league matches + 1 final fixture.
- Ball-by-ball scoring.
- Need live scores, player stats, highest scorer, highest wickets, Man of the Match, points table and NRR.

SPECIAL RULES
First 2 overs are female-only:
1. Both batting players must be female.
2. Bowler must be female.
3. Female batter cannot be normally dismissed in first 2 overs.
4. If a female batter is marked OUT in first 2 overs: actual wickets do NOT increase; team score decreases by 2; delivery counts as a ball; same batter stays; store special_event='female_protected_wicket', dismissed_player_id=<batter>, score_adjustment=-2.
5. Female wide in first 2 overs = +2 runs and counts as a legal/valid ball.
6. Female no-ball in first 2 overs = +2 runs and counts as a legal/valid ball.
7. After 2 overs, normal/global cricket rules apply: wide +1 and not legal; no-ball +1 and not legal; wickets are real.
8. Female return rule: a female opener who survives the complete first 2 overs without ever receiving the protected-out event becomes eligible to return later. A female who had a protected-out event is never eligible. When exactly one male batter remains in the innings, an eligible female can return. Each eligible player's return privilege can be used once. Protected-out is never counted as a real wicket.

PLAYER RULE
- Playing 9 must contain 2–4 female players per team.
- First two batters and first bowler must be female.
